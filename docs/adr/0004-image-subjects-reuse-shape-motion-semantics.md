# Image Subjects reuse Shape Motion semantics

`--image PATH` lets a raster image replace the NLTL Shape as the render's Subject. Rather than designing image-specific effects, every Motion keeps its existing meaning and Preset numbers keep their existing scale. The Image is contained (aspect-preserved, alpha respected) inside the same bounding square the Shape would occupy for that Motion, so `deform_amplitude`, `scale_amplitude`, `split_amplitude` and `pulse_max_opacity` mean the same thing for either Subject. The Image's own pixels take the place of the Palette's `outline_color`. The Palette still supplies the background and flash colors.

## Considered Options

- **What `deform` warps along.** We use the Image's contain-box rectangle as a stand-in for the polygon perimeter: bands are spread around it by arc length, starting at its top-left corner and running clockwise, as for a Shape. Each pixel is pushed radially from the rectangle's centre by the scale at the point where its ray meets the edge. Because a pixel's scale depends only on its angle, the warp inverts exactly, so it is rendered as a per-pixel inverse lookup (no triangle mesh, so no seams). Tracing the **alpha silhouette** of a cut-out PNG would follow the visible subject more faithfully, but we rejected it because contour extraction breaks on holes, multiple islands and noisy edges, and it does nothing for an opaque JPEG. It can be revisited as a refinement.
- **Where the flash goes.** A Shape under `deform` is a hollow stroked outline, so its gradient flash, drawn first, shows through. An opaque Image would hide it completely, so for Images the flash is composited **on top** (additive), masked to the Image's alpha so it never spills past the Image's edges. Under `rigid` the inner flash copy becomes a flash-colored silhouette of the Image (its alpha).
- **Filling the frame** instead of containing it in the Shape's square was rejected: Images would look larger, but every Preset amplitude would need separate tuning for Image Subjects, which reintroduces the "same number, different meaning" problem ADR 0002 removed.
