# `Preset` splits into three independent axes: motion-tuning, palette, layout

The flat `Preset` dataclass mixed motion tuning (`deform_amplitude`, `smoothing_attack`, `grain_strength`, ...) with color (`bass_color`, `treble_color`, `background_color`, `outline_color`). In practice this made the built-in presets feel repetitive: `industrial`/`subtle`/`aggressive` all shared the same black-background color scheme and only varied by tuning *numbers*, while `3d-glasses` was the sole preset that read as visually distinct — and only because it changed color, not motion.

We split `Preset` into three independently-combinable settings: `--preset` (motion tuning, unchanged field set minus color), a new `--palette` (background/outline/flash color scheme), and a new `--layout` (`single` or a fixed 2×2 `grid` of 4 identical shape copies). Unlike the `Motion` flag ADR 0002 removed — where a preset's amplitude fields only made sense paired with the one `Motion` they were tuned for — color and layout carry no per-motion-tuned semantics: a hex color or a grid arrangement means the same thing regardless of which `Motion`/tuning preset is active. Splitting them out doesn't reintroduce the mismatch problem ADR 0002 fixed.

`3d-glasses` is retired as a named preset: its only distinguishing trait was an off-brand (non-NLTL) light color scheme, now expressible as a `--palette` instead of a whole preset, and its tuning numbers were already identical to `subtle`'s — nothing distinct is lost.

`--palette` resolves the same way `--preset` already does: a closed set of built-ins (`black`, `violet`, `teal` — violet `#6E5470` and teal `#2E8C8A` are NLTL's brand colors, already the pre-split defaults for `bass_color`/`treble_color`) plus `--config`-defined custom palettes. `black` keeps today's two-color flash lerp by spectral centroid; `violet`/`teal` are single-accent (monochrome — no lerp), with a shared neutral off-white background (`#F2F0EF`, reused from the retired `3d-glasses`) so the two read as a matched pair.
